# AI Companion 1.0.0

The first Windows release of AI Companion, an independent local companion for Codex and Claude.

## Download

- **AI-Companion-1.0.0-Setup-x64.exe** — Windows x64 installer with shortcuts.
- **AI-Companion-1.0.0-Windows-x64.zip** — extract the entire archive and run AI Companion.exe; no Node.js installation needed.

The binaries are unsigned. Windows may show an unknown-publisher warning. Windows 11 is the tested platform.

## Included

- Combined and per-provider usage analytics, local history, charts, project privacy controls, and CSV / clipboard reports.
- A resizable circular widget with persistent position, size, and always-on-top settings.
- Amber pulses for newly reported Codex allowance crossings at 80% and 95%.
- Blue pulses for new explicit unanswered input requests from active local chat turns, with stale/startup suppression and local dismissal.
- Shared Codex + Claude branding, portable source launch scripts, and migration of legacy dashboard preferences.

## Data and notification limits

The app reads local records; it does not query your account or upload chat history. Cost figures are standard API-equivalent estimates, not subscription charges. Missing local activity cannot be reconstructed.

Chat notifications require supported explicit input-tool records. Idle chats and ordinary final answers do not trigger them. Plain-text questions, generic permission prompts, silently closed chats without a close event, and tools hidden inside execution wrappers cannot be reliably detected.
